# 사회조사분석사 2급 필기 학습노트

교재 OCR 결과에서 **핵심이론 · 기출문제 · 해설**을 자동 추출해 만든 모바일 학습 웹앱입니다.
문제를 풀면 넘어가고, 틀린 문제는 오답노트에 자동으로 쌓입니다.

## 기능

- **이론** — 「빨리보는 간단한 키워드」 185개 토픽을 과목별로 정리 + 검색
- **문제풀이** — 챕터별 진행. 맞히면 자동으로 다음 문제, 틀리면 정답·해설을 보여주고 오답노트에 저장
- **해설노트** — 문제 해설 999개를 챕터별 학습카드로 정리 + 검색
- **오답노트** — 틀린 문제 모아보기, 다시풀기, 맞히면 자동 해제
- 진도·오답 기록은 브라우저 `localStorage`에 저장 (서버 없음)

## 수록 데이터

| 구분 | 수량 |
|---|---|
| 이론 토픽 | 185 |
| 기출문항 | 1,106 |
| 정답 확인된 문항(풀이 가능) | 735 |
| 해설 | 999 |

과목·챕터 구성

- **PART 1 조사방법과 설계** — 통계조사계획 / 표본설계 / 설문설계 / FGI 및 심층인터뷰 정성조사
- **PART 2 조사관리와 자료처리** — 자료수집방법 / 실사관리 / 2차 자료 분석 / 측정의 타당성과 신뢰성 / 자료처리
- **PART 3 통계분석과 활용** — 확률분포 / 기술통계분석 / 회귀분석
- **PART 4** — 2025년 기출복원문제

## 구조

```
docs/
  index.html   앱 전체 (단일 파일, 외부 의존성 없음)
  data.js      추출된 학습 데이터 (window.DATA)
```

`docs/index.html`을 브라우저로 바로 열어도 동작합니다.

## 배포 (GitHub Pages)

저장소 **Settings → Pages → Source: `main` 브랜치 / `/docs` 폴더** 로 설정하면
`https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.

## 알아두기

원본 PDF를 OCR한 자료라 띄어쓰기가 붙어 있거나 수식·표가 깨진 부분이 있습니다.
정답을 교재 정답표와 대조하지 못한 문항은 풀이에서 제외하고 **해설노트**에서만 볼 수 있게 했습니다.
학습용 개인 자료이며, 교재 저작권은 원저작자에게 있습니다.

## 데이터 재생성

```bash
OCR_MD="교재 OCR 마크다운 경로.md" python tools/build_data.py docs/data.json
# 앱은 window.DATA 를 읽으므로 data.js 로 감싼다
python - << 'PY'
d = open('docs/data.json', encoding='utf-8').read()
open('docs/data.js', 'w', encoding='utf-8').write('window.DATA=' + d + ';')
PY
```
